# KSEF 따라하기

중고등학생이 KSEF(Korea Science & Engineering Fair) 과학프로젝트대회를 혼자서도 준비할 수 있도록 만든 한 페이지 인터랙티브 안내 사이트입니다.

- 대회요강(KSEF 2027 National·International·GENIUS Olympiad Korea·KASTIC·특별 카테고리)
- 일정 타임라인, D-day
- 분과 찾기, 파일명·입금자명 생성기, 제출서류 체크리스트
- 기간별 준비 로드맵(막차 플랜 / 1년 플랜 / 국제대회)
- 연구 따라하기 10단계, 논문 목차 템플릿, 초록 800자 작성기
- 7분 발표 타이머, 예상 질문, 공식 심사기준 자가진단
- 기 수상작·국제대회 진출작, 주제 아이디어 뱅크, 자료실

비공식 학습용 사이트입니다. 최신 일정·규정은 반드시 공식 사이트 http://www.ksef.or.kr 에서 확인하세요.
